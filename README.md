# MPM Player

Reproductor multimedia para Android basado en LibVLC, con biblioteca local de archivos y una interfaz de reproducción inspirada y parcialmente derivada de VLC for Android.

## Atribución

Parte de la interfaz del reproductor está basada en VLC for Android, proyecto de VideoLAN:
https://github.com/videolan/vlc-android

MPM Player es un proyecto independiente, no oficial y no afiliado a VideoLAN.
