# VLC Android layout reference

All 155 XML layout files copied unchanged from VideoLAN VLC for Android.

- Upstream: https://github.com/videolan/vlc-android
- Source revision: 6cc45524d62128377f5a5c51b57c3293699aa87f
- Original directory: application/vlc-android/res/layout/
- License: GPL-2.0-or-later, as stated by the upstream project.

These files are preserved as reference assets, not compiled Android resources. This prevents unresolved VLC-specific resources, bindings, and custom views from breaking MPM Player. They can now be selectively integrated and adapted to MPM's LibVLC playback implementation.
